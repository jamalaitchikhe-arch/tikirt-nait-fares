# موقع مجموعة مدارس تيكرت نايت فارس

الموقع الرسمي لمجموعة مدارس تيكرت نايت فارس (المديرية الإقليمية ورزازات)، ويضم الوحدة المركزية وفرعيات تايفست وتماكوشت وآيت فارس.

تم الإنشاء بواسطة **نادي الإبداع وتنمية المهارات**.

## محتوى المستودع
- `index.html` : صفحة الموقع
- `header.jpg` : الترويسة الرسمية للمؤسسة
- `.nojekyll` : لنشر الملفات كما هي على GitHub Pages

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا عامًا (Public) على GitHub، مثلًا باسم `tikirt-nait-fares`.
2. اضغط **Add file ← Upload files** وارفع الملفات الثلاثة، ثم **Commit changes**.
3. ادخل إلى **Settings ← Pages**، واختر في **Source**: `Deploy from a branch`، ثم الفرع `main` والمجلد `/ (root)`، واضغط **Save**.
4. بعد دقيقة أو دقيقتين يصبح الموقع متاحًا على الرابط:
   `https://اسم-المستخدم.github.io/tikirt-nait-fares/`
